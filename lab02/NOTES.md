## Git vs GitHub

- **Git** — это распределённая система контроля версий (локальная программа). Она позволяет отслеживать изменения в файлах, создавать коммиты, ветки и т. д. Работает на твоём компьютере.
- **GitHub** — это веб-сервис для хостинга Git-репозиториев. Он предоставляет интерфейс для совместной работы, просмотра истории, создания pull request’ов и т. п. Это не сама система контроля версий, а площадка для хранения Git-репозиториев. ## Использованные команды

- `git status` — показывает текущее состояние репозитория: какие файлы изменены, какие добавлены в индекс, какие не отслеживаются.
- `git diff` — сравнивает рабочую папку с индексом/последним коммитом (показывает изменения, которые ещё не добавлены через `git add`).
- `git diff --staged` — сравнивает индекс с последним коммитом (показывает изменения, которые уже добавлены через `git add` и попадут в следующий коммит).
