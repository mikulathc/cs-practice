## Git vs GitHub

- **Git** — это распределённая система контроля версий (локальная программа). Она позволяет отслеживать изменения в файлах, создавать коммиты, ветки и т. д. Работает на твоём компьютере.
- **GitHub** — это веб-сервис для хостинга Git-репозиториев. Он предоставляет интерфейс для совместной работы, просмотра истории, создания pull request’ов и т. п. Это не сама система контроля версий, а площадка для хранения Git-репозиториев.
