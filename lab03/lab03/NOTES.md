## Пункт 2. Сравнение версий и поиск изменений

### Разница между командами

- `git log` (с флагом `--stat`) показывает хронологию коммитов и статистику изменений. Это «летопись» проекта.
- `git diff` показывает построчную разницу между версиями (строки с `-` и `+`).
- `git show` раскрывает детали одного конкретного коммита: сообщение автора и сам diff.

### Результаты поиска

- `git log -S"def"`: Найдена история изменений ключевого слова. Результат: коммит `426e933` (`feat: add calc.py with basic operations`). Это доказывает, что поиск по содержимому кода работает.
- `git blame lab03/calc.py`: Показано, что все строки файла `lab03/calc.py` были добавлены в коммите `426e933`. Это подтверждает, что файл был создан целиком в рамках этой лабораторной работы.
