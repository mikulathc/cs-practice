# Журнал воркшопа lab03

## Инициализация
Команда: `git switch -c lab03`
Результат: Создана новая ветка lab03 для изоляции эксперимента.

Команда: `mkdir lab03`
Результат: Создана папка проекта.
## Коммит 1: Сложение
Команда: `git commit -m "feat: add calc.py
 with addition only"`
Результат: Зафиксировано первое состояние проекта. Теперь можно вернуться к нему в любой момент.
## Коммит 2: Вычитание
Команда: `git commit -m "feat: add subtraction support"`
Результат: Калькулятор теперь умеет вычитать. История проекта содержит два состояния.
## Коммит 3: Умножение
Команда: `git commit -m "feat: add multiplication support"`
Результат: Калькулятор теперь умеет умножать. История проекта содержит три состояния.
- `git log` — просмотр истории коммитов (хэш, автор, дата, сообщение).
- `git diff` — сравнение изменений между состояниями репозитория.
- `git revert <hash>` — создание коммита, отменяющего указанный.
- `git restore` — восстановление файлов до состояния коммита.
- Тег (tag) — метка для версии (коммита), обычно для релизов.
